# Aura Estética — Clínica de Estética Avançada e Bem-Estar

Landing page interativa e responsiva desenvolvida para clínica de estética de alto padrão, com agendamento via WhatsApp, avaliador de protocolos personalizado e vitrine de especialidades.

---

## Como executar o projeto localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- npm

### Passo a passo

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Para gerar a versão de produção:
   ```bash
   npm run build
   ```

---

## Tecnologias utilizadas
- **React 19** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Framer Motion** (animações e transições fluidas)
- **Lucide React** (ícones vetoriais)
